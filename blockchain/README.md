# PhishFree — Blockchain Threat Intelligence Registry

## Overview
This directory contains the Solidity smart contract, Hardhat environment, testing suites, and deployment scripts for **Module 6: Decentralized Threat Intelligence using Blockchain**.

The `ThreatReportRegistry.sol` smart contract provides tamper-evident, decentralized proof-of-existence and integrity verification for forensic threat analysis reports generated by PhishFree.

> **Integrity Scope:** The blockchain records deterministic Keccak-256 fingerprints, timestamps, and submitter addresses. It provides public, independent verification that a report has not been altered since registration. It does **not** determine whether a website is malicious.

---

## Smart Contract Architecture

- **Contract Name:** `ThreatReportRegistry`
- **Location:** `contracts/ThreatReportRegistry.sol`
- **Solidity Version:** `^0.8.20`
- **Target Network:** Ethereum Sepolia Testnet (Chain ID `11155111`) / Localhost (Chain ID `31337`)

### Key Methods
- `registerReport(bytes32 reportHash) external returns (bool)`: Registers a 32-byte Keccak-256 report digest. Rejects zero hashes and prevents duplicate registration.
- `verifyReport(bytes32 reportHash) external view returns (bool exists, bytes32 registeredHash, uint256 timestamp, address submitter)`: Checks if a hash exists on-chain and returns provenance metadata.
- `isReportRegistered(bytes32 reportHash) external view returns (bool)`: Boolean existence query.
- `getTotalReports() external view returns (uint256)`: Returns the total count of registered reports.
- `getRecentReports(uint256 count) external view returns (ThreatReport[] memory)`: Returns recent reports in reverse chronological order for dashboard feeds.

## 3. Running Local Smart Contract Tests

A comprehensive 13-test suite covers all lifecycle operations:
```bash
npx hardhat test
```

### Test Coverage (13 Tests, 100% Passing):
1. **Contract Deployment:** Verifies initial 0 count and deployer owner address.
2. **Report Registration:** Validates registration of 32-byte hash and counter increment.
3. **Zero Hash Rejection:** Reverts with `"Invalid report hash: zero hash rejected"` on `bytes32(0)`.
4. **Duplicate Prevention:** Reverts with `"Report hash already registered"` on duplicate submission.
5. **Successful Verification:** Returns `exists=true`, matching hash, timestamp, and submitter.
6. **Unknown Hash Verification:** Returns `exists=false` and zeroed values for unregistered hashes.
7. **Timestamp Recording:** Confirms block timestamp accuracy.
8. **Submitter Recording:** Confirms recording of caller wallet address.
9. **Event Emission:** Validates `ReportRegistered(bytes32 indexed reportHash, address indexed submitter, uint256 timestamp)` event emission.
10. **Details Validation:** Reverts on `getReportDetails` for unregistered hashes.
11. **Reverse Chronological Recent Feed:** Verifies LIFO ordering of recent registrations.
12. **Bounds Handling:** Gracefully handles counts larger than total registered.

## 4. Deploying to Local Hardhat Network

Start local JSON-RPC node:
```bash
npx hardhat node
```

In a separate terminal, deploy:
```bash
npx hardhat run scripts/deploy.js --network localhost
```

---

## 5. Deploying to Ethereum Sepolia Testnet

1. Ensure your backend `.env` contains:
   ```env
   SEPOLIA_RPC_URL=https://ethereum-sepolia-rpc.publicnode.com
   BLOCKCHAIN_PRIVATE_KEY=your_testnet_wallet_private_key_without_0x_or_with_0x
   ```
2. Request Sepolia testnet ETH from a public faucet:
   - [Google Cloud Web3 Sepolia Faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)
   - [Sepolia PoW Faucet](https://sepolia-faucet.pk910.de/)
   - [Alchemy Sepolia Faucet](https://sepoliafaucet.com/)
3. Run the deployment script:
   ```bash
   npm run deploy:sepolia
   ```
4. Note the output contract address and update `.env`:
   ```env
   THREAT_REGISTRY_CONTRACT_ADDRESS=0xYourDeployedContractAddress
   ```

## 6. Backend Integration

The FastAPI backend automatically:
- Canonicalizes reports using `ReportCanonicalizer` (deterministic sorting, normalized floats, excluded UI fields).
- Hashes using standard Ethereum Keccak-256 via `ReportHashService`.
- Connects to Sepolia via `BlockchainService` (`web3.py`).
- Manages on-chain registration and database persistence (`BlockchainReportRegistration`).
- Conducts independent tamper verification (`ReportVerificationService`).
